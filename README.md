# Blinkit Retail Sales Analysis using SQL

## 📌 Project Overview

This project analyzes Blinkit's retail sales dataset using SQL to understand
product performance, sales patterns, outlet characteristics, pricing and
customer-oriented product attributes.

The analysis focuses on extracting business insights from retail transaction
data using SQL queries and aggregation techniques.

---

## 🎯 Business Objective

The objective of this project is to analyze retail sales data and answer
business questions related to:

- Product and item performance
- Item type distribution
- Product pricing and MRP
- Outlet characteristics
- Outlet location and type
- Item visibility
- Sales performance
- Fat-content based sales
- Tier-wise product sales

---

## 🗂️ Dataset

The dataset contains information related to retail products and outlets,
including:

- Item Identifier
- Item Weight
- Item Fat Content
- Item Visibility
- Item Type
- Item MRP
- Outlet Identifier
- Outlet Establishment Year
- Outlet Size
- Outlet Location Type
- Outlet Type
- Item Outlet Sales

## 🔍 Analysis Performed

### 1. Data Exploration

- Total number of items
- Minimum, maximum and average item weight
- Minimum and maximum MRP
- Unique product and outlet categories

### 2. Product Analysis

- Item count by item type
- MRP analysis by item type
- Item visibility by item type
- Sales performance by item type

### 3. Outlet Analysis

- Outlet size distribution
- Outlet location type distribution
- Outlet type distribution
- Sales performance by outlet type
- Sales analysis by outlet characteristics

### 4. Sales Analysis

- Total sales by item type
- Total sales by fat content
- Sales by outlet type
- Sales by outlet location
- Tier-wise sales analysis

## 📊 Key Business Questions

Some of the questions explored in this project include:

1. Which item categories have the highest number of products?
2. Which item types generate higher total sales?
3. How does sales performance vary across outlet types?
4. How does product MRP vary by item category?
5. How does item visibility vary across categories?
6. How do sales differ based on item fat content?
7. Which item types generate higher sales in Tier 1 locations?

---

## 📈 Business Value

The analysis can help retail businesses understand:

- Product category performance
- Outlet-level sales patterns
- Pricing differences
- Product visibility
- Sales contribution across categories
- Differences in performance across outlet segments
